# Plantillas Instagram

Guardar fuentes editables (AI, PSD, SVG, Figma exportado u otros) con sus vistas previas.

Formatos:
- Feed vertical: 1080 × 1350 px (4:5), preferido.
- Feed cuadrado: 1080 × 1080 px.
- Stories/Reels: 1080 × 1920 px.

Series propuestas:
1. `editorial-frases/`: frases contundentes y minimalismo.
2. `servicios/`: fotografía, video, diseño, 3D, vinil y DTF.
3. `producto/`: materiales, texturas, procesos y detalles.
4. `carruseles/`: educativos y demostraciones.

Aplicar siempre `marca/guias/IDENTIDAD.md`. No insertar logos recreados.
