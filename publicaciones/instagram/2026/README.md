# Publicaciones Instagram · 2026

Por campaña crear carpeta `AAAA-MM-DD-tema/` con:
- `post-01.png` o `post-01.jpg` — arte final.
- `copy.md` — texto de publicación, CTA, hashtags y alt text.
- `metadata.json` — formato, estado, versión y origen de recursos.

Estados: borrador → revisión → aprobado → publicado.

**No publicar automáticamente:** validar logo original, tipografía, contraste, texto, derechos y precios.
